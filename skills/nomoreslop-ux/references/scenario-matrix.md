# Сценарная карта интерфейсов

Выбирай по задаче участков, а не по названию отрасли. Карта покрывает семейства и механики, не утверждает, что перечисляет все возможные интерфейсы. Для нового случая выводи путь из principles и общих решений; не создавай новый процесс только из-за другого продукта.

| Семейство | Главное решение и структура | Риск / проверяемый путь |
| --- | --- | --- |
| Лендинг, услуга, кампания | Понять предмет/условия, оценить доказательства и выбрать нужное продолжение; материал задаёт порядок | Рассказать, что предлагается, найти условие и выполнить действие; без выдуманных обещаний и одинакового hero/CTA всех секций |
| Портфолио, галерея, культурный проект | Рассмотреть работы, авторство/контекст и связь между ними; допустим свободный просмотр | Найти/открыть работу, вернуться в нужное место; выразительность не заменяется таблицей или обязательной продажей |
| Статья, журнал, документация | Читать, ориентироваться и найти ответ по смыслу; headings/содержание/поиск по масштабу | Перейти к вопросу, прочесть с медиа/сносками, вернуться; без рекламной нарезки каждого абзаца |
| Каталог, подбор, маркетплейс | Найти, отфильтровать, сопоставить нужные характеристики | Сравнить несколько объектов, изменить фильтр, открыть и вернуться с контекстом; сетка по изображениям или таблица по сравнению |
| Продукт, кейс, объект | Рассмотреть существенные свойства, доступность/вариант и реальные условия | Выбрать совместимый вариант и понять результат; выбранное и показанная цена согласованы |
| Тарифы, подписка | Сопоставить состав, ограничения, единицу/период и смену плана | Выбрать по нужде, увидеть полные условия и отмену/изменение; без выдуманного «популярного» |
| Корзина, checkout, пожертвование | Состав/получатель, итог, обязательные сведения, проверка и подтверждённый исход | Изменить количество/доставку, пережить ошибку оплаты, проверить отсутствие дубля; не реализовывать платёж вне задания |
| Бронирование, расписание, билет | Совместимость даты/времени/места, длительность, доступность и цена | Сменить слот без тихой потери данных, учесть timezone/недоступность, получить настоящий статус; выбор не равен резервации |
| Анкета, заявление, конфигуратор | Зависимые/независимые задачи, обязательность, ветвление, прерывание и проверка | Сменить условие, исправить ошибку, продолжить и проверить отправляемое; wizard/task list по зависимости, не по моде |
| Auth, приглашение, восстановление | Понятный вход существующего и первого пользователя, роль и продолжение | Истёкшая ссылка/сессия, повторный вход и восстановление без создания случайного нового аккаунта |
| Onboarding, обучение | Освоить действительно новую возможность с контролем темпа | Начать полезную работу, пропустить/вернуться к помощи по задаче; не навязывать тур очевидного |
| Настройки, предпочтения | Группы по смыслу, зависимости, момент применения и риск | Изменить, отменить/сохранить, увидеть ошибку и действующий результат; не карточка на каждое поле |
| Кабинет, CRM, back office | Обзор/список, поиск, объект, действие и продолжение | Найти/сравнить/изменить/вернуться, сохранить selection и ввод; API/права не подменены fixture |
| Очередь, moderation, batch | Идентичности, охват, пригодность, последствия и частичный результат | Выбрать через сортировку/страницы, выполнить над теми ID, восстановиться без дубля; команда доступна |
| Dashboard, отчёт, мониторинг | Вопрос решения, определения показателей, период/основание, требующее внимания | Отличить ноль/unknown/error, понять сравнение и открыть соответствующие данные; не декоративные KPI |
| Редактор текста/медиа, IDE | Рабочий предмет, частые команды, параметры, история и сохранность | Внести изменение, отменить/повторить, сменить контекст и восстановить; не потерять данные вне главной формы |
| Карта, граф, canvas, 3D-viewer | Найти/сопоставить пространственное, масштаб/selection, детали и выход | Выбрать объект без обязательного сложного жеста, reset/обзор по задаче, нужная альтернатива; не добавлять пульт декоративной сцене |
| Файлы, импорт, экспорт, загрузчик | Формат, пределы, прогресс, сопоставление и результат | Ошибочный/частичный файл, cancel/retry, сохранность уже принятого; скачивание/принятие не равно завершению обработки |
| Чат, inbox, уведомления | Контекст беседы, адресат/аудитория, прочитанное и реальные статусы | Отправить в правильный контекст, различить queued/delivered, вернуться к непрочитанному; не ложный успех |
| Совместная работа | Участники, присутствие, права, локальное/общее и конфликт | Одновременное изменение, разрыв сети, повторное соединение; не перезаписать чужую работу молча |
| Offline, фоновые операции | Локальный результат, ожидание синхронизации, подтверждение и восстановление | Прерывание/возврат, лимит/таймаут и unknown; нет фиктивной постоянной зелёной готовности |
| AI-помощник, генерация | Исходный материал, неопределённость, ход, исправление и принятие | Остановить/повторить без потери ввода, проверить/исправить результат; backend/автопубликация не придуманы |
| Mobile, tablet, kiosk, desktop | Доступная область, способы ввода, система и продолжение той же задачи | Keyboard/IME/insets, несколько панелей, короткое окно/ориентация; web-demo не доказывает native-реализацию |
| Ошибка, пустота, обслуживание | Конкретная причина и доступное продолжение с сохранностью контекста | Различить первый запуск, no results, completed, permission denied, offline и outage; не один одинаковый CTA везде |
| После действия: заказ, обращение, отмена, возврат | Найти подтверждённый объект/номер, состояние, следующий шаг и доступную помощь | Вернуться позже, уточнить исход, изменить/отменить в поддержанных границах; экран успеха не завершает весь сервис |
| Приватность, согласия, общий терминал | Понятные цель/область/последствия разрешения, доступный отказ и смена решения по реальным условиям | Не смешать необязательный выбор с обязательным действием, не оставить чужие данные следующему посетителю; правовые сроки/обязанности не выдумываются |
| Медиа, урок, интерактивная демонстрация | Управление темпом, контекст, место воспроизведения и нужные альтернативы | Приостановить/продолжить/вернуться без потери места; значимый смысл не зависит только от звука, жеста или эффекта в применимом объёме |

Особые домены — здоровье, деньги, образование, дети, чувствительные/необратимые операции — меняют последствия ошибки и контекст, но не дают навыку компетенцию придумывать правовые/медицинские требования. Подтверди реальные условия через профильные источники при необходимости. Не увеличивай сбор данных и не заявляй compliance из одной UX-оценки.

## Перекрёстные оси

Одно семейство проверь в относящихся условиях: новичок/опытный; первое/повторное использование; мало/много объектов; длинное/многоязычное; роли; медленная сеть/частичный ответ; низкая/высокая цена ошибки; pointer/touch/keyboard; широкий/узкий/короткий viewport; спокойное/выразительное направление. Не проходи полное декартово произведение: выбери случаи, в которых меняется решение или растёт риск, и назови оставшееся непроверенным.
