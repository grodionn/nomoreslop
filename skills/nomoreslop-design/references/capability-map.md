# Карта возможностей и точек проверки

Открывай для разбора процесса, выбора нужной ветки или проверки покрытия задания. Это навигация по действующим инструкциям, не обязательная анкета и не список эффектов для каждого сайта. Полные условия находятся по ссылкам; не загружай все справочники одновременно.

| Задача | Где читать | Наблюдаемый результат |
| --- | --- | --- |
| Новый сайт, существенный редизайн, продолжение работы | [Поэтапный процесс](staged-workflow.md) | Точное содержание, действующий бриф, выбранная схема, текущие основания и проверки |
| Сохранить ценное в существующем интерфейсе | [Редизайн](redesign-workflow.md) | Разобрано исходное состояние; определены сохраняемое и допустимая глубина изменений |
| Разобраться с неопределённым запросом | [Бриф](brief-and-decisions.md), [иерархия интервью](design-interview.md) | Нужные вопросы с проектными вариантами и рекомендацией; известное и делегированное не спрашивается повторно |
| Связать смысл, материал, конструкцию и поведение | [Интервью](design-interview.md), [арт-дирекшн](art-direction.md) | Понятно, что посетитель увидит, выберет и получит; список фич не подменяет сценарий |
| Отобрать факты и написать интерфейс | [Редакторский процесс](content-workflow.md), [текстовые признаки](antipatterns/text.md) | Точные тексты до разметки; лишние надписи удаляются вместе со слотом |
| Найти текст внутри реализации и состояний | [Инвентаризация в редакторском процессе](content-workflow.md), `scripts/audit_project.py --help` | Кандидаты HTML/SVG/JS/TS/JSX/CSS и доступных подписей, наблюдения собственного рендера, расхождения с каноном и явные пробелы покрытия |
| Выбрать ресурсы по промпту | [Базовые источники](solution-sources.md) | Использованы релевантные входы из сохранённого пула; специализированный поиск вызван конкретным дефицитом |
| Выбрать среди находок, не остановиться на главной | [Глубокий отбор](resource-selection.md), [структура поиска](resource-pipeline.md#проверка-глубины-отбора) | Выведены теги проекта, выполнены тематические запросы и внутреннее изучение; стиль, компоновка и UX сопоставлены с альтернативой до принятия |
| Получить и применить готовую основу | [Готовые решения](ready-solutions.md) | Код/вариация/альтернатива/собственная реализация различаются; источник и выбранное свойство прослеживаются до актуального результата |
| Продолжить при paywall или квоте | [Маршруты доступа](ready-solutions.md), [конкретный источник](solution-sources.md) | Разрешённая публикация автора, доступный экспорт, открытая альтернатива либо честная собственная реализация; доступ и происхождение не выдуманы |
| Разработать три схемы | [Арт-дирекшн](art-direction.md), [24 направления](style-directions.md) | Различаются содержание, первый кадр, ритм, материал и поведение, а не только цвет |
| Выбрать выразительные средства шире scroll/parallax | [Подбор приёмов](technique-selection.md), [66 записей](technique-index.md) | Сочетание композиции, набора, графики, материала и взаимодействия имеет задачу и ограничения |
| Подобрать набор и цвет | [Шрифтовой ресерч](font-research.md), [типографика](antipatterns/typography.md), [цвет](antipatterns/color-material.md) | Язык, роли, начертания, фактическая читаемость, цветовые отношения и состояния проверены по проекту |
| Сохранить идентичность, избежать случайных фигур | [Айдентика](brand-assets.md), [изображения](antipatterns/imagery.md) | Использован подтверждённый знак; графический мотив связан с материалом и характером |
| Спроектировать предметное 3D | [Сцена](scene-design.md) | Замысел, отдельный черновой кадр, форма, материалы, свет и движение проверяются до интеграции |
| Проверить иконки, кнопки, слайдеры, вложенные демо | [Управление](antipatterns/controls.md), [проверка](review.md) | Оптическое выравнивание, масштаб, обещанный результат, hitbox, координаты и состояния согласованы |
| Проверить обратный ход, покой, повтор и курсор | [Движение](antipatterns/motion.md), [проверка](review.md) | Отклик соответствует состоянию; нет конкурирующего лишнего указателя; нужные клавиатурный и спокойный варианты доступны |
| Довести страницу целиком | [Типы страниц](page-playbooks.md), [композиция](antipatterns/layout.md), [проверка](review.md) | Продолжение, футер, контакт и материалы проработаны наравне с hero |
| Повторять подбор по новому решению | [Ресурсный конвейер](resource-pipeline.md), [источники](solution-sources.md) | Проверенный комплект и наблюдаемое свойство доходят до текущего участка |
| Рабочий web, desktop или mobile | [Платформенные сценарии](platform-workflows.md) | Привычное управление, навигация, состояние, окно и ввод соответствуют платформе |
| Разработать выраженный характер | [Разобранные конструкции](design-recipes.md) | Материал, действие, результат и узкий вариант связаны, а не набор украшений |
| Проверить известные ошибки и исключения | [Регрессионный процесс](regression-workflow.md), `library.py checks ID...` | Выбранные признаки проверены на текущем артефакте, не по одному совпадению строки |
| Сверить текущую версию после замены | [Состояние и актуальность](staged-workflow.md), [проверка](review.md) | Повторены затронутые проверки; старые кадры не объявлены доказательством новой сцены |

Для поиска дополнительного признака используй [индекс антипаттернов](antipattern-index.md). Это контекстный каталог решений, не автоматический детектор авторства. Структурная валидность скилла, сборка проекта, логические тесты, редактура, визуальный результат и сходство выбранных свойств с источником отвечают на разные вопросы.
