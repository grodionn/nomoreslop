# Источники шрифтов: точка перехода

Каноническая карта открытых шрифтов, письменностей и программных маршрутов находится в `nomoreslop-typography`: `references/font-sources.md` и `font-sources.json`. Найди навык в действительном каталоге, прочитай SKILL.md и нужные разделы. В design второй независимо изменяемый каталог не ведётся.

Эта страница сохраняет прежние ссылки design. Передача задачи описана в [font-research.md](font-research.md). Шрифтовые источники используются специалистом сразу по задаче; ожидать исчерпания UI-каталогов не требуется. Издатель, бесплатная цена и metadata не заменяют проверку конкретной лицензии/файла. Карту ресурсов и font_catalog.py вызывай из фактического каталога typography, а не из design.
