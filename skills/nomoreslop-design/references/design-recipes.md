# Конструкция экрана из задачи

Определи, какое решение принимает человек, какие материалы он должен видеть вместе и что должно сохраниться после действия. За основу возьми реальные данные, состояния и ограничения среды.

Сопоставь способы организовать это содержание. Для каждого опиши первый видимый материал, путь к действию и наблюдаемый результат. Выбор должен выдерживать изменения количества объектов, длины текста и доступного места. Если решение опирается на сторонний компонент, проверь его по [ресурсному процессу](ready-solutions.md).

В чёрно-белом каркасе пройди основной маршрут на фактическом содержании. После детализации повтори его в целевых размерах, с подходящими для платформы способами ввода и возвращением к предыдущему состоянию, если оно есть.

Для проверки готовой конструкции доступны [шесть разборов с заданными условиями](../checks/design-recipes.md).
