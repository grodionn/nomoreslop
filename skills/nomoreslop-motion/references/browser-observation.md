# Наблюдение и воспроизведение движения

Используй, когда выбор зависит от вида/поведения демо или нужно сравнить реконструкцию с референсом. Исходники и каналы — в [карте доступа](source-access.md), состояния/создание — в [компонентном гайде](component-production.md).

## Канал и отбор

Для браузерного исследования и проверки разрешён только Browser MCP **встроенного браузера Codex**. Выбирай провайдера in-app (`iab`, если так называется тип), читай фактическую документацию; не переключайся на внешний Chrome/Edge, desktop control или отдельный headless/Playwright. Встроенные документированные locators/developer-capabilities допустимы. Отсутствие официального MCP сайта не препятствует HTTP, реестру, авторскому source либо поиску/просмотру через IAB. Если IAB недоступен, используй оставшиеся разрешённые каналы и сохрани визуальный пробел. Доступ/квоты/оплата не обходятся.

Сначала выведи поисковые признаки из функции/стиля/состояний/стека и сравни пригодные внутренние варианты. Углубляй browser-наблюдение там, где осталось существенное неизвестное. Не открывай по очереди все сайты и не заменяй отбор первым компонентом ради экономии.

## Восстановление механики

| Что исследуется | Что наблюдать / фиксировать |
| --- | --- |
| Dropdown/popup/expand | Исходное и открытое состояние, origin/геометрию, вход/выход, быстрый reopen, изменение размера/стороны при применимости |
| Hover/press/interactive | Вход/уход, область ответа, удержание/отпускание, покой и повтор; hover наблюдается только реально поддержанным действием инструмента |
| Morph/SVG/gooey | Конечные формы, доступные промежуточные силуэты/маску/stroke, слои текста и материал; crossfade не объявляется path morph |
| Scroll/reveal/pin | Container, видимые границы, несколько относящихся позиций, обратный ход и пропуск диапазона; время trigger и scroll progress различаются |
| Slider/toggle/swap/nav | Настоящее значение/selection, направление, thumb/indicator/track, оба перехода и быстрый повтор |
| Loading/progress/loop | Pending/завершение/ошибку и повтор/остановку по реальной операции; неизвестные проценты и FPS не угадываются |

Для короткого движения предпочитай доступную запись, авторский code/config или документированное временное наблюдение. Используй запись/инспекцию параметров только если текущий браузерный инструмент действительно это поддерживает. Не приписывай произвольному JS canvas возможность получить CSS timing и не выдавай несколько послеоперационных снимков за полный motion capture.

Screenshot показывает кадр; DOM snapshot — структуру/состояние. Ни один из них сам по себе не даёт точную Bézier, duration, spring velocity или частоту кадров. Если инструмент автоматически ждёт завершения, вход уже мог исчезнуть до снимка. Известный config и приблизительная оценка на глаз сохраняются раздельно. При неполной наблюдаемости воспроизведение остаётся реконструкцией, а timing — неподтверждённым/приближённым.

## Экономный цикл сравнения

Начни с определяющего свойства на небольшом образце. Сопоставь референс и собственный компонент при одинаковых viewport/геометрии и соответствующих states/actions/scroll-position. Сравни масштаб, origin, порядок фаз, соответствие вводу, конечный покой и обратимость; затем проверь в общей композиции. К чужому содержимому и стеку не привязывай всю страницу.

Запрашивай компактный DOM для поиска/состояния, screenshot для визуального вопроса; оба нужны лишь при разных незакрытых вопросах. Сохраняй несколько информативных состояний, не поток полностраничных кадров. Кроп оставляет опорную геометрию; полный viewport нужен для ритма/контекста. Для нового дефекта снимай затронутую фазу; сохраняй полезные прошлые наблюдения вместо повторного сбора. Свежая ground truth после действий остаётся обязательной по документации инструмента.

В `motion_system` используй существующую запись: reference URL, переносимое свойство, среда/состояние/действие, доступные параметры/артефакт, отличие собственной версии и предел проверки. После исправления повтори связанный цикл; не делай новый проход без конкретного вопроса. Экономия не отменяет проверку exit/interrupt/reverse/reduced и не даёт квоту «один ref на сайт». Цена и процент экономии не гарантируются, модель/скорость/платные настройки не меняются автоматически.

Полученный source, наблюдение внешнего демо, собственный runtime, сравнение и performance trace — разные свидетельства. Не называй реконструкцию импортом оригинала и не обещай точное совпадение движения по одним endpoints. Если замер или визуальное сравнение недоступны, продолжай доступную работу с конкретным ограничением.
