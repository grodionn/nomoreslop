Проверка каналов: **29 октября 2026**. Это карта доступа и отбора под motion-задачу; она не заменяет канон реализации, просмотр собственного результата и условия конкретного файла. ## 1. От запроса к пригодному кандидату

Запиши функцию движения, исходное/целевое состояние, источник управления, характер, свойства, окружение и стек. «Dropdown anchored to trigger, enter/exit, quick restrained settle, keyboard/Escape, React with Radix» позволяет сравнивать решения; «красивые анимации» — нет. Для scroll нужны также контейнер, участок пути, связь с прогрессом и обратное направление.

Ищи по нескольким относящимся осям: **функция** (`accordion`, `menu`, `slider`, `route transition`, `path drawing`), **механика** (`shared layout`, `height auto`, `presence`, `drag`, `scroll progress`), **характер** (`restrained`, `snappy`, `elastic`, `gooey`) и **контекст проекта**. Последняя ось не должна заменять первые. Если сервис поддерживает теги/категории, возьми реальные значения его каталога; если поддерживает только строку запроса, не придумывай JSON-фильтры.

Исследуй внутреннюю карточку/пример и альтернативу до фиксации. Не принимай первый популярный компонент, прежнюю пару компонентов или showcase-hero за решение продуктового UI. При изменении направления возвращайся к относящемуся поиску. Для локальной коррекции принятой кривой/состояния свежая сеть не обязательна, если актуальная основа уже подтверждена.

## 2. Easing Wizard: проверенный REST и MCP

[Главная](https://easingwizard.com/) публикует ссылки на [REST docs](https://api.easingwizard.com/docs) и пакет `@easingwizard/mcp-server`. HTML docs — оболочка Scalar; она указывает **`/openapi`**, не `/openapi.json`. В [полученной схеме](https://api.easingwizard.com/openapi) `servers[0].url` — **`https://api.easingwizard.com/v1`**. Получение docs само не является генерацией кривой.

Подтверждённые операции:

| REST после `/v1` | Существенные параметры |
| --- | --- |
| `GET /presets` | необязательный `type`: `BEZIER`, `SPRING`, `BOUNCE`, `WIGGLE`, `OVERSHOOT` |
| `GET /curves/{id}` | существующий ID из ответа/ссылки; неизвестный ID не изобретать |
| `POST /curves/bezier` | JSON `x1,y1,x2,y2`: x в [0,1], y в [-1,2] по API |
| `POST /curves/spring` | `mass` [1,5], `stiffness` [0,100], `damping` [0,100], `accuracy`: LOW/MEDIUM/HIGH/ULTRA |
| `POST /curves/bounce` | `bounces` [1,10], `damping`, `accuracy`; дополнительные поля сверять по текущей схеме |
| `POST /curves/wiggle` | `wiggles` [1,10], `damping`, `accuracy` |
| `POST /curves/overshoot` | `style`: IN/OUT/IN_OUT, `mass`, `damping`, `accuracy` |

Предел y — ограничение сервиса, не полный допустимый диапазон CSS. Шкалы mass/stiffness/damping сервиса не являются прямыми параметрами Motion/GSAP или универсальными физическими единицами. Не переносить числовой spring config между движками без сопоставления и проверки.

Реально выполнены `GET /v1/presets?type=BEZIER`, `POST /v1/curves/bezier` с `{x1:0.16,y1:1,x2:0.3,y2:1}` и `POST /v1/curves/spring` с `{mass:1,stiffness:60,damping:70,accuracy:"HIGH"}` — все HTTP 200. Ответы содержали `output.css`, Tailwind-представление, SVG-данные и ссылку/ID; spring также дал `suggested_duration_ms`. Диапазон длительности сервиса — предложение, не норматив для меню/сайта. Те же пути **без `/v1` вернули 404**: не считать это отказом всего API.

В [MCP README](https://github.com/roydigerhund/easingwizard/blob/main/apps/mcp/Readme.md) встречаются camelCase-имена, но [текущий исходник mapping](https://github.com/roydigerhund/easingwizard/blob/main/packages/core/src/text/endpoints.ts) объявляет `get_presets`, `get_curve_by_id`, `create_bezier_curve`, `create_spring_curve`, `create_bounce_curve`, `create_wiggle_curve`, `create_overshoot_curve`. Пользуйся **реально показанной клиентом схемой**, а не одним старым примером. npm metadata пакета получены; MCP-сервер в этой сессии не запускался. Нет необходимости устанавливать сервер ради REST-доступа.

Сохрани параметры и полученную CSS-кривую; не делай сеть зависимостью каждой анимации в готовом сайте. Sampled `linear()` подходит для воспроизводимой временной кривой, но не сохраняет физическую velocity retargeting как настоящий spring runtime.

## 3. Motion: бесплатная механика и отдельная готовая выдача

Официальные [AI Kit docs](https://motion.dev/docs/ai-kit-context) и [репозиторий](https://github.com/motiondivision/ai-kit) описывают поисковый канал. [Manifest](https://github.com/motiondivision/ai-kit/blob/main/plugins/motion/mcp.json) указывает `https://mcp.motion.dev` и отдельный `https://mcp.motion.dev/plus`.

По текущему [описанию поиска в авторском source](https://github.com/motiondivision/ai-kit/blob/main/plugins/motion/skills/motion/codex/index.md): `search-motion-docs({platform,searchTerm})`, где platform — `js`, `react` или `vue`; searchTerm — предмет (`accordion`, `useSpring`, `drag`, `shared layout`), а не одно слово `animation`. Результат может дать resource links: их нужно прочитать, metadata сама не является файлом. `search-motion-source` относится к авторизованной выдаче готовых source; существование matching demo не подтверждает доступ к его коду. Реальные имена/аргументы проверяются в клиенте. В этой проверке Motion MCP не был подключён.

Сведения о tier генерации CSS easing расходятся между страницей установки и более новым текстом репозитория. Не закрепляй бессрочное обещание «free» или «только Plus»: проверь наличие инструмента и ответ доступа. В source описан `generate-css-easing({kind,duration,bounce})`, kind spring/bounce; duration — perceptual time, возвращённый settle может длиться дольше. При недоступности есть проверенный REST Wizard и собственная реализация свободными API.

Бесплатная библиотека [`motiondivision/motion`](https://github.com/motiondivision/motion) и опубликованные docs содержат достаточные API для присутствия/выхода, gesture, layout, SVG и scroll. Не импортируй Plus-компонент из `motion/react` и не устанавливай private-package без доступа. Не подменяй существующий `framer-motion` во всём проекте автоматически ради взятого примера: версия и миграция — отдельное решение, сохраняй рабочий стек.

Эталонные механики: [AnimatePresence](https://motion.dev/docs/react-animate-presence) для exit lifecycle и [layout/layoutId](https://motion.dev/docs/react-layout-animations) для непрерывности элемента при смене расположения. Это опоры для реализации, а не лицензия копировать любую премиальную композицию по описанию. Если закрыт конкретный source, назови предел и выбери свободную основу/собственный паттерн; не выдавай результат за тот самый закрытый пример.

## 4. GSAP: plugin → пример → собственная timeline

[Документация](https://gsap.com/docs/v3/) и [Demo Hub](https://demos.gsap.com/) позволяют выбрать механику по plugin: ScrollTrigger/ScrollSmoother, Flip, DrawSVG, MorphSVG, MotionPath, Draggable/Inertia и др. Найди внутренний demo нужной задачи и его опубликованный исходник, изучи trigger/timeline/cleanup, не только название эффекта. Статичный каталог не доказывает качество на телефоне.

По текущей [pricing-странице](https://gsap.com/pricing/) прежние платные плагины включены бесплатно. [Standard License](https://gsap.com/community/standard-license/) допускает обычные сайты/интерфейсы, но содержит условия, в том числе для конкурирующих визуальных animation builders; это не MIT. Само создание кода агентом разрешено в FAQ. Не заставляй пользователя покупать прежний Club ради DrawSVG/MorphSVG и не называй бесплатность безусловной открытой лицензией.

Для обучения отрисовке бери [DrawSVG](https://gsap.com/docs/v3/Plugins/DrawSVGPlugin/), для изменения контура — [MorphSVG](https://gsap.com/docs/v3/Plugins/MorphSVGPlugin/), для DOM-reflow — Flip. Эти механики различны: SVG stroke reveal, morph путей и геометрический layout transition не заменяют друг друга. Сверь форму путей, transform origin, порядок и семантическое состояние. Исходник конкретного чужого сайта не извлекается из bundle как «готовый открытый проект».

## 5. Компонентные источники: текущий формат и комплект

### Animate UI

[Документация v2.4](https://animate-ui.com/docs/installation) описывает `@animate-ui/react` + `motion`, используя уже выбранные `radix-ui`, `@base-ui/react` либо `react-aria-components`. CLI умеет адресную миграцию с `animate accordion --dry-run`; команда `animate all` меняет множество компонентов и не запускается автоматически ради одного запроса. Это разрешённый способ подготовить изменения к review, но не основание мигрировать стек без задачи.

[MCP](https://animate-ui.com/docs/mcp) использует shadcn registry `@animate-ui: https://animate-ui.com/r/{name}.json`; нынешняя область реестра — styled components, icons и backgrounds. Index [`/r/registry.json`](https://animate-ui.com/r/registry.json) реально получен; в нём выбран `buttons-liquid` и получен [его JSON](https://animate-ui.com/r/buttons-liquid.json). Реестр не обещает каждую package primitive под её старым slug.

Текущий [dropdown source](https://github.com/imskyleen/animate-ui/blob/main/packages/react/src/primitives/radix-ui/dropdown-menu/dropdown-menu.tsx) реально прочитан и делегирует общим menu helpers: один файл не является комплектом. В [лицензии](https://github.com/imskyleen/animate-ui/blob/main/LICENSE.md) указана **MIT + Commons Clause**, поэтому не называй её обычной MIT. Изменение названия версии не обнуляет условия конкретного выпуска.

### Magic UI

Есть [официальный MCP](https://magicui.design/docs/mcp), публичный registry и [авторский source](https://github.com/magicuidesign/magicui). Область Pro отделяется от свободных items; существование MCP не подтверждает его подключение. HTTP 200 с inline source получены для [blur-fade](https://magicui.design/r/blur-fade.json), [morphing-text](https://magicui.design/r/morphing-text.json), [animated-circular-progress-bar](https://magicui.design/r/animated-circular-progress-bar.json). У blur-fade заявлен `motion`; у остальных metadata без dependencies не доказывает отсутствие imports/helpers. [Лицензия core](https://github.com/magicuidesign/magicui/blob/main/LICENSE.md) — MIT; условия Pro проверяются отдельно.

### Animata

[Каталог](https://animata.design/docs) содержит группировку функций и внутренние примеры; [Gooey Tabs](https://animata.design/docs/tabs/gooey-tabs) ведёт к [авторскому source](https://github.com/codse/animata/blob/main/animata/tabs/gooey-tabs.tsx). Файл и соседний `shared.ts` прочитаны через raw HTTP. Наблюдаются SVG filter, layout-движение и keyboard helpers; перенос одного TSX без shared/helper/CSS ломает комплект. Официальный специальный API/MCP здесь не подтверждён; обычные GitHub contents/raw и docs достаточны. [Лицензия](https://github.com/codse/animata/blob/main/LICENSE.md) — MIT.

### React Bits, Componentry, Aceternity

Документированы shadcn namespaces [@react-bits](https://reactbits.dev/get-started/mcp), [@componentry](https://componentry.dev/docs/mcp) и Aceternity registry. Имена/версии бери из каталога; варианты TS/JS/CSS/TW не синтезируй наугад. Для Aceternity используй [AI-каталог](https://ui.aceternity.com/ai-recommendations), различая free/pro до запроса кода. Free registry не является выдачей Pro.

| Реально полученный registry | Наблюдение по исходнику | Что ещё нужно проверить |
| --- | --- | --- |
| [React Bits SplitText TS TW](https://reactbits.dev/r/SplitText-TS-TW.json) | `gsap`, `@gsap/react`, ScrollTrigger/SplitText; источник содержит cleanup listeners | Языковой набор, повтор/выход, reduced motion, SSR и fonts-ready; не добавлять splitting всем текстам |
| [Componentry Magnetic Dock](https://componentry.dev/r/magnetic-dock.json) | `framer-motion`, `@/lib/utils`, springs и reduced-motion ветка | Хитбоксы, клавиатура/touch, масштаб/tooltip и версия движка; магнитность не должна уводить действие |
| [Aceternity Animated Modal](https://ui.aceternity.com/registry/animated-modal.json) | `motion/react`, React, локальный `cn`, presence и outside-click handlers | Native dialog semantics/фокус/Escape/возврат фокуса/scroll lock: красота entrance не подтверждает эти свойства |
| [Animate UI Liquid Button](https://animate-ui.com/r/buttons-liquid.json) | `@animate-ui/react`, `motion/react`, отдельный import `cn` | Нельзя считать `cn` автоматически стандартным `@/lib/utils`; проверь настоящий dependency/helper и состояния |

[React Bits](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md) использует MIT + Commons Clause, [Componentry](https://github.com/harshjdhv/componentry/blob/main/LICENSE) — MIT. Для Aceternity проверь [условия выбранного материала](https://ui.aceternity.com/licence), зависимости/медиа имеют отдельные условия. Не распространяй downloaded code в документации навыка как собственную библиотеку.

## 6. Эталонные примеры: что изучать и что не копировать

«Эталон» означает пригодную учебную опору для конкретной механики, не доказательство её безусловного превосходства и не обязательный дизайн всем проектам.

| Пример | Полезная техника | Как адаптировать и принять |
| --- | --- | --- |
| Motion AnimatePresence | Элемент остаётся смонтирован на время exit; enter/exit связаны со состоянием | Проверить rapid close/reopen, фокус и отсутствие невидимого интерактивного слоя; exit не задерживает нужное действие |
| Motion layout/layoutId | Продолжение идентичности при expand/перемещении/смене selection | Устойчивые ID, проверка масштаба текста/border radius, нового контента и прерывания |
| Animate UI dropdown primitive | Motion поверх настоящего menu primitive | Связь transform origin с anchor/collision; закрытие, Escape, клавиатура и nested menus сохраняются |
| Animata Gooey Tabs | Подвижная заливка и filter с переходом между выбранными пунктами | Связать с реальной selected state; оставить текст резким и независимым от фильтра, проверить несколько экземпляров и стоимость эффекта |
| Magic UI morphing text | Визуальная смена слов с blur/opacity | Не выдавать за настоящий SVG path morph; не ухудшать обязательный смысл/скринридер и не делать бесконечный цикл в каждом hero |
| Magic UI circular progress | Дуга вокруг числа/значения | Значение от реального процесса, determinate/indeterminate различны; шаг назад и смена диапазона работают, проценты не выдуманы |
| GSAP DrawSVG/MorphSVG docs | Stroke drawing и отдельно форма контура | Свой SVG/viewBox/направление и path topology; последующее состояние читается и при reduced motion |
| Componentry Dock | Pointer-distance response и плавное возвращение | Уместен при таком навигационном сценарии; размер/target/focus и mobile fallback важнее копирования полного desktop-эффекта |

## 7. Получить, адаптировать, проверить

Перед переносом установи настоящий import graph и комплект: исходник + локальные helpers/styles + registry dependencies + package versions + assets + license/notices. Registry с непустыми `files[].content` подтверждает получение кода, но `dependencies:[]` не заменяет чтение imports. Не исполняй внешний bundle для «поиска».

Сохраняй платформу и действующий стек. Для simple state CSS/WAAPI может быть достаточно; Motion полезен для React lifecycle/gestures/layout, GSAP — для согласованных сложных timelines и plugins. Один участок не должен одновременно управляться competing CSS transition, Motion и GSAP. Декоративное движение и настоящий control-state разделены: обновление модели не ждёт окончания визуального tween.

В запись выбранного решения включи source URL/версию/дату, функцию и начальные/конечные состояния, реально изученные альтернативы, выбранные свойства/easing/duration, reduced-motion вариант, зависимости и предел проверки. Затем настрой под проект цвета/темы, текстовые роли, плотность и геометрию, сохраняя полезную механику. У scrollbar/reveal/slider назначь точные границы/контейнеры вместо magic viewport assumptions.

При ограничении доступа: разрешённая авторская публикация → подходящая открытая основа → самостоятельная реализация по доступной механике. Называй `author_variant`, `compatible_alternative` или `reconstructed`, если это другой source. Не пересылай заблокированную выдачу через другие клиенты ради обхода квоты и не придумывай баланс MCP. Промпт, screenshot и реестр — не один формат.

На собственном результате проверь завершение и прерывание, оба направления, repeat/reentry, resize/zoom/длинный контент, pointer/keyboard/touch, reduced motion, teardown и фактическую стоимость. Сеть/прочитанный code не подтверждают плавность и соответствие референсу; `render_unverified` сохраняется, пока просмотр не выполнен.

**Что именно перепроверено.** Все семь основных маршрутов выше получили читаемый публичный документ через HTTP 200: Awwwards SOTD; HorizonX MCP; Mobbin MCP features + API quickstart; MotionSites MCP; 21st MCP + CLI; FreeFrontend index; официальный Refero `mcp-tools.md` через GitHub raw. Refero `/mcp` в прямом веб-чтении вернул пустую SPA-оболочку; вывод о схемах опирается на официальный опубликованный reference, не на эту оболочку. Чтение FreeFrontend было ограничено первыми 1,5 МБ: в этом фрагменте найдены публичные `pre` с HTML/CSS/JS и `data-original`, полный каталог не выгружался. Awwwards microinteractions-ссылка присутствует в прочитанном индексе, но отдельный запрос страницы завершился timeout; это не успешное углубление в конкретный референс. Эти проверки подтверждают канал/формат, а не качество анимации и не доступ аккаунта.

**Разделяй доказательства.** `static_screen` даёт компоновку/состояние; `flow_sequence` — порядок состояний; `motion_media` — только действительно полученную запись с пределами наблюдения; `source_inspected` — изученную реализацию; `render_verified` — проверку собственного исполнения. Нельзя вывести длительность/кривую/интерактивную отзывчивость из одиночного screenshot или объявить prompt импортированным компонентом. Для внутреннего поиска, карточки/демо и движения разрешён Browser MCP только встроенного браузера Codex по [наблюдению движения](browser-observation.md); MCP сайта не обязателен. Внешние браузеры/desktop control/отдельный headless запрещены. При недоступном воспроизведении сохрани пробел, возьми авторский разбор/разрешённое медиа либо другой кандидат. Выбирай информативные состояния вместо потока кадров; собственный результат сравни с выбранным свойством, не выдавая endpoints за измеренный timing.

**Стилевые специалисты подключаются по пробелу.** Если обычные ресурсы дают недостаточно материала именно под согласованный стиль, сформулируй недостающее свойство (геометрия, плотность, поведение, характер переходов), затем ищи профильный источник и его официальную документацию/публичный source. Neubrutalism/RetroUI — возможные примеры, не обязательная очередь и не лицензия ставить один стиль во все проекты. Сохраняй тот же маршрут поиска, сравнения, проверки кода/условий и соответствия задаче.
