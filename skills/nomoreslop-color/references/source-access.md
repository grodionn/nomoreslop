# Поиск цвета: Colorsinspo и Refero

Проверено 27 октября 2026 через web/HTTP и официальную документацию. Доступность и схема меняются; отличай живой ответ от сохранённого наблюдения. Выбирай нужный источник по задаче, не создавай журнал посещений ради количества.

## Colorsinspo: палитры и градиенты через публичный HTML

Официальные входы — [палитры](https://colorsinspo.com/color-palettes), [градиенты](https://colorsinspo.com/gradients) и [отдельные цвета](https://colorsinspo.com/solid-color). Они выбираются по задаче; одним listing исследование не ограничивается. На проверке все три вернули HTTP 200 и карточки в HTML без исполнения JavaScript. Документированный публичный API/MCP не найден; это не доказательство его вечного отсутствия. Не используй придуманный `/api/palettes`, приватные вызовы приложения и реконструкцию внутренних endpoints. [robots.txt](https://colorsinspo.com/robots.txt) исключает `/api/`, `/search` и некоторые query-фильтры; пользуйся открытыми тематическими путями и обнаруженными ссылками.

### Как искать от задачи

1. Выведи признаки от проекта: например, холодные малонасыщенные поверхности для плотной рабочей среды, или близкие тёплые пигменты для фотографии продукта. Не своди любой продукт к одному эмоциональному слову.
2. Получи нужный тематический hub и выбери его настоящую ссылку. На проверке существовали [hue](https://colorsinspo.com/color-palettes/hue), [temperature](https://colorsinspo.com/color-palettes/temperature), [harmony](https://colorsinspo.com/color-palettes/harmony). Среди обнаруженных значений: red/orange/yellow/green/teal/cyan/blue/indigo/violet/pink/brown/gray/black/white; cool/warm/neutral/contrast; analogous/complementary/monochromatic/tetradic/split-complementary/triadic/achromatic/contrast. Текущую таксономию перечитай, не превращай этот список в API-enum.
3. Изучи относящиеся категории, затем внутренние карточки кандидатов. Запросы `/color-palettes/temperature/neutral` и `/color-palettes/harmony/monochromatic` дали отличные от главной выборки. Классификация — подсказка, не математическое доказательство гармонии; проверь сам рисунок сочетания и роль цветов.
4. На listing извлекай HEX из кнопок `aria-label="Copy RRGGBB"` **внутри карточки** и связывай их с её ссылкой/названием. Не собирай все `#xxxxxx` страницы: среди них цвета навигации и чужих UI-предпросмотров. Детальная карточка даёт дополнительные classifications, значения и иногда CSS-экспорт. Порядок цветов не определяет `background/text/accent` будущего продукта.
5. Для градиента сохрани карточку, точный CSS и ссылку на detail. На проверке listing содержал `style="background:linear-gradient(...)"`, а detail показывал угол, цвета и позиции остановок. Например, проверен [Charcoal Quiet](https://colorsinspo.com/gradients/charcoal-quiet-6f34a3e0); это технический образец получения, не рекомендуемый пресет для всех проектов. Не путай его CSS с градиентом hover в навигации.
6. Переходи по настоящей ссылке следующей страницы только пока это добавляет материал. Сравни набор item URL/цветов с прежним. На проверке `/color-palettes/2` вернул те же 16 карточек, что главная; такой ответ не считается новой страницей кандидатов. Тематические категории при этом работали. При повторе смени относящуюся ветку, используй индексируемые внутренние страницы через программный поиск или другой разрешённый источник. Не обходи повтор скрытым API или браузерной автоматизацией.

Программный поиск при конкретном пробеле: `site:colorsinspo.com/color-palettes/ <тема/температура/характер>` или `site:colorsinspo.com/gradients/ <материал/тип/характер>`. Это запрос поисковику, не поддержка параметра `q` сайтом. Проверь найденную карточку: snippet не заменяет её содержимое.

### Отдельные цвета: /solid-color и /color/HEX

Используй `/solid-color`, когда нужно уточнить фирменный оттенок, подобрать глубину нейтрали, уменьшить цветность без потери характера или построить собственную систему вокруг цвета материала. Это дополнение к палитрам и градиентам, а не обязательное посещение всех разделов в каждой локальной задаче.

Проверены HTTP 200: [Solid Colors](https://colorsinspo.com/solid-color), [Saturation](https://colorsinspo.com/solid-color/saturation), [Lightness](https://colorsinspo.com/solid-color/lightness) и [детальная карточка](https://colorsinspo.com/color/4c4f56). Хабы показывали saturation soft/vivid/balanced/muted и lightness mid/light/dark/very-light/very-dark. Есть также hue и temperature; значения выбирай из актуальных ссылок. Классификацию каталога не выдавай за универсальный психофизический порог.

В listing карточка `<article>` находится **внутри** ссылки `/color/4c4f56`, значение дано кнопкой `aria-label="Copy #4c4f56"`, имя — карточкой/label ссылки. Парсер учитывает отличие от palette-card. Detail содержит свойства и связанные оттенки; их можно изучить для кандидатов. Название и текст о «спокойной стабильности» являются описанием сервиса, не научным исследованием. Отдельный HEX ещё не образует нейтральную шкалу, функциональные роли и пару тем — их нужно спроектировать и проверить.

Для градиентов используй `/gradients` и найденные type/temperature/harmony ветки; для solid — `/solid-color` и его ветки; для готовых сочетаний — `/color-palettes`. Если нужна дальнейшая глубина, переходи по карточкам/related-ссылкам и проверяй новые результаты. Не синтезируй путь `/gradient` по аналогии: в проверенной навигации канонический раздел называется `/gradients`.

### Почему экспорт нужно проверять

На карточке [Dusty Sunrise](https://colorsinspo.com/color-palettes/dusty-sunrise) HTML-экспорт назначил `--palette-background:#72D6C9` и `--palette-text:#FFC785`. Расчёт sRGB даёт около **1.13:1**. Это наблюдение конкретного экспорта, не оценка всего сервиса: сочетание цветов может служить вдохновением, а роль обычного текста требует другой пары. На странице есть и APCA-показатели; их нельзя выдавать за WCAG 2.2 contrast ratio.

[Gradient Studio](https://colorsinspo.com/gradient-studio/) и его [официальный guide](https://colorsinspo.com/blog) описывают CSS/SVG/JSON/raster-экспорт. Наличие кнопки экспорта в приложении не подтверждает программный endpoint. Без доступного документированного API получай опубликованный CSS/метаданные или строй собственный градиент по изученному направлению. Не заявляй получение сложного editable-документа, если прочитан только текст страницы.

В [действующих условиях](https://colorsinspo.com/terms-of-service) отдельно разрешён пример копирования HEX для проектов. Не переноси это на изображения, статьи, весь каталог, исходники редактора и сторонние freebies. Храни ограниченную рабочую выборку, не зеркаль сервис.

## Refero: контекст применения и структурированные стили

Предпочтителен [официальный MCP](https://refero.design/mcp), производственный адрес `https://api.refero.design/mcp` подтверждён [официальным репозиторием](https://github.com/referodesign/refero_skill). Живое исследование требует авторизованного платного доступа; установка методики/репозитория сама не даёт данные. Не подключай сервер, не меняй конфигурацию и не оформляй подписку автоматически ради подбора цвета. Используй уже доступные инструменты; отсутствие подключения не выдавай за отсутствие материала.

Документированный маршрут [инструментов](https://github.com/referodesign/refero_skill/blob/master/skills/refero-design/references/mcp-tools.md):

| Задача | Инструмент и существенные параметры | Что принимать |
| --- | --- | --- |
| Цветовой характер/арт-дирекшн | `refero_search_styles(query, page?)` | ID, контекст и превью кандидатов; поиск от эстетики, домена и аудитории |
| Углубление выбранного стиля | `refero_get_style(style_id либо style_ids, response_format?)` | Цветовые роли, поверхности, правила применения, типографический/композиционный контекст |
| Применение цвета в продукте | `refero_search_screens(query, platform, page?)` → `refero_get_screen(screen_id либо screen_ids)` | Форма, данные, действия, состояния и конкретный экран |
| Нужен точный просмотр | `refero_get_screen_image(screen_id, image_size?)` | Изображение как материал анализа, а не исходный код/точные токены |

Имена и аргументы используй **только по схеме, реально показанной клиентом**. Не добавляй search-параметры `limit`, `image_size`, `include_similar` без поддержки. `style_id` берётся из результата, не из названия бренда. Полные стили велики: получай несколько сильных кандидатов, не весь каталог. Styles ориентирован прежде всего на web marketing/product pages; для dashboard, settings и mobile изучай screens, не обещай отдельную стилевую систему iOS из неподходящей коллекции. Потоки нужны, когда вопрос касается смены состояния в последовательности, а не для каждой палитры.

Запросы составляются под проект: настроение + отрасль/материал + характер интенсивности; затем конкретный экран/состояние. Например, для камерного каталога авторских изделий полезнее исследовать светлую предметную фотографию, пигментные акценты и низкую визуальную плотность, чем повторять «premium blue trustworthy». Не застревай на известном Linear и не превращай его кислотный акцент в стандарт каждого тёмного продукта.

### Публичный резерв и границы происхождения

[Refero Styles](https://styles.refero.design/) предоставляет отдельные общедоступные карточки. На проверке известная [карточка Linear](https://styles.refero.design/style/90ce5883-bb24-4466-93f7-801cd617b0d1) вернула HTML с цветами, описаниями ролей и представлениями DESIGN.md/CSS/Tailwind. Это подтверждение одного маршрута, не подтверждение всех карточек и экранов. Она описывает интерпретацию референса; не называй её официальными токенами Linear. Не считай сохранённый пример релевантным текущему брифу без нового отбора.

Для публичного резерва используй индексируемую подходящую карточку, её человеческий HTML и первичную доступную публикацию продукта. У [robots](https://styles.refero.design/robots.txt) есть отдельные правила для named bots и запрет `/api/` для общего обхода; не меняй user-agent ради обхода правила. Не используй сторонний неофициальный MCP как автоматическую замену авторизованному: проверь происхождение и разрешённый канал отдельно. Если доступ ограничен, Color продолжает с Colorsinspo/официальными системами и явно помечает неполученный слой Refero.

## Компактный след решения

Для принятого кандидата сохрани source URL/ID, дату и канал, запрос/категорию, реально полученные цвета/градиент/роли, отличие от альтернативы и способ адаптации. Отдельно укажи, где значение авторское, извлечённое, приблизительно измеренное по изображению или созданное агентом. Повтор URL и новый HTTP 200 не доказывают новое содержание, художественную пригодность или реализацию в продукте.
