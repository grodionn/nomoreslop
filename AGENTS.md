# Repository instructions

This package contains agent skills, documentation, and tool checks.

Store conversations, attachments, screenshots, third-party project sources, and raw work logs only in the ignored `.local/` directory. Receiving a file in chat does not authorize publishing it.

The repository is private. Public access requires an explicit instruction from the owner after they have reviewed the prepared contents.

Keep the README focused on purpose and usage. Detailed rules belong in the reference library. Do not add a demonstration until its quality and included materials have been approved by the owner.

Before completing changes, run the commands in [CONTRIBUTING.md](CONTRIBUTING.md). Do not present structural checks as an assessment of design quality.
