# Работа с репозиторием

Пакет содержит скилл, документацию и проверки его инструментов.

Материалы диалогов, вложения, скриншоты, исходники сторонних проектов и сырые журналы работы сохраняйте только в игнорируемой папке `.local/`. Получение файла в чате не означает разрешения на его публикацию.

Репозиторий приватный. Публичный доступ допускается только по явному поручению пользователя после просмотра им подготовленного состава.

README кратко объясняет назначение и использование скилла. Подробные правила остаются в библиотеке. Не добавляйте демонстрацию, пока её качество и состав материалов не согласованы с пользователем.

Перед завершением изменений выполните команды из [CONTRIBUTING.md](CONTRIBUTING.md). Не выдавайте проверку структуры за оценку качества дизайна.
