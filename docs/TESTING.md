# Проверка

Из корня репозитория, Python 3.9+:

```sh
python skills/nomoreslop-design/scripts/library.py check
python -m unittest discover -s tests -p "test_*.py" -v
python scripts/check_repo.py
```

Эти команды проверяют целостность библиотеки, работу CLI, переносимость установки и локальные ссылки документации. Сторонние зависимости не требуются.

[Сценарии поведения](../skills/nomoreslop-design/checks/scenarios.md) предназначены для отдельных прогонов. Передавайте исполнителю запрос и специально подготовленные материалы; ожидания оставляйте проверяющему. Подготовленный сценарий не считается выполненным тестом.

Качество дизайна оценивается по артефакту и задаче. Проверки инструментов не заменяют такую оценку. Материалы диалогов и внутренние журналы не входят в распространяемый пакет.
