# Использование скилла

Опишите задачу страницы, аудиторию, главное действие и доступные материалы. Если важны бренд или утверждённый текст, укажите, что нужно сохранить.

Обозначьте границы самостоятельности: какие решения хотите обсудить, а какие поручаете исполнителю. Для небольшой правки достаточно точного задания; полный процесс проектирования нужен при существенном изменении дизайна.

Оценивайте сначала общую композицию и содержание макета, затем детали. Проверяйте результат на нужных устройствах и проходите главное действие.

У скилла есть библиотека справочников. Загружайте материалы текущего этапа, сохраняя принятые решения для продолжения работы.

Для проверки поведения используйте отдельное задание и новый контекст. Условия оценки оставьте проверяющему. Совпадение с форматом или успешный запуск инструмента не подтверждают качество дизайна.

Используйте специально подготовленные данные для демонстраций. Право использовать материалы в работе и разрешение публиковать их нужно различать.
